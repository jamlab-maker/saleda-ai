# Saleda AI — Full Site (Static)

This folder is a multi-page static site inspired by ElevenLabs’ design patterns.

## Run locally

It’s easiest to run the server from the project root (one level above `saleda/`).

```bash
cd /Users/jamiebyun/Desktop/Restaurant-Website-Demo
python3 -m http.server 7832
```

Then open:

- `http://localhost:7832/saleda/index.html`

## Pages

- `index.html`: Home + inline “Talk to Maya” demo
- `platform.html`: Platform / workflow
- `agents.html`: Demo playground (scenario chips)
- `integrations.html`: Integration search + filter
- `security.html`: Security page + FAQ accordion
- `pricing.html`: Monthly/annual toggle + volume estimator
